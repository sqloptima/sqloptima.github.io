Dummy guide: nested views and mega-queries hide bad estimates.

Rewrite the monster into named CTE stages for humans, then materialize expensive stages into
`#temp` tables when the optimizer keeps underestimating. Index the temp when the next step
filters or joins on it more than once.

Do not assume every CTE is materialized — in SQL Server it usually is not. Measure with actual
plans, not folklore.
