Dummy guide: exact duplicates are easy; near-duplicates hide in INCLUDE lists.

Compare key column order first, then included columns. If index A is a strict subset of index B
and both are nonclustered, B usually wins — but verify uniqueness, filtered predicates, and
compression settings before you drop A.

Document the change in your change ticket so the next incident does not recreate the duplicate
from an old create script.
