Dummy guide: rewrite for readability and cardinality first.

Pull non-SARGable expressions off columns, remove redundant joins, and collapse OR trees that
block index seeks. Only then consider hints or plan forcing.

If the rewrite still needs a hint, you probably still have a stats or indexing problem — treat
the hint as temporary evidence, not the fix.
